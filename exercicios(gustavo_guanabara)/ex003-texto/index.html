Texo marcado

tu tambem pode uar um marca texto para dar destaque a alguma coisa usando a tag "mark"
uma oservação interessante é que vc pode configurar a cor do marca texto utilizando css

a tag em css é "style"

para cor individual

se quiser usar o marca texto com uma cor especifica uma vez você pode usar a tag "style= background-color: cor "
veja um exemplo de uma frase seblinhada

Para cor geral

se você quiser definir uma cor de marca texto para usar em todas as suas marcações da pagina, vc pode adicionar um parametro dentro do cabeçalho do codigo em "head", colocar uma tag "style" e então a tag "mark" dentro e adicionar um parametro, "{ background-color: cor }
